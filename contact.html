FAQ

  • The game won't load? Make sure JavaScript is enabled. The game works on all modern browsers.
  • No sound? Click anywhere on the game canvas first — browsers require user interaction before playing audio.
  • Lost my high score? High scores are stored in your browser's local storage. Clearing browser data will reset it.
  • Want more levels? Let us know! We're always adding new content.
